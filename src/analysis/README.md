# analysis scripts (archival)

These reproduce the result tables/figures in `results/` and `figures/` from the raw outputs in `results/raw/`. They were authored against a flat working directory and reference raw files by name; run them from a directory containing the raw outputs (or adjust the paths at the top of each file). Provided for full transparency/audit, not as a turnkey pipeline. The turnkey, zero-key entry point is `src/models.py` (see root README).
